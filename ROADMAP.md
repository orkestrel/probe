# Roadmap

Each item is a chunk that reaches green before the next. An item keeps its number for life: a closed item leaves this file and its number is never reused, so a commit message citing an item by number stays true.

- **1.** Start the probe when the server starts, so a workspace that cannot arm shows at the onset instead of at the first `prove`: `ProbeServer.start()` (`src/server/ProbeServer.ts:105-126`) serves standard input and constructs no `Probe`; the first admitted `prove` constructs it (`#resolveProbe`, `src/server/ProbeServer.ts:234-245`), and only then does the constructor arm the stages (`src/server/Probe.ts:159`), so the Oxlint language server, the Vitest service, and the compiler warm-up start inside that call. A failed arm is reported to that call and retried once by each later call (`#ready`, `src/server/Probe.ts:229-242`), and an Oxlint server that exits between calls is recorded (`#retire`, `src/server/stages/LintStage.ts:156`, `:173-175`) and reported only when a later inspection reaches it (`:246`). Construct and arm the `Probe` at server start, report an arming failure through the server before any call depends on it, and replace a worker that exits as soon as it exits, so no `prove` pays a startup or meets a dead worker. The user ruled this on 2026-10-03 for every tool server, beside the same change to `@orkestrel/browser`'s `browse` server.
