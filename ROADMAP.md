# Roadmap

Each item is a chunk that reaches green before the next. An item keeps its number for life: a closed item leaves this file and its number is never reused, so a commit message citing an item by number stays true.

- **1.** Start the probe when the server starts, so a workspace that cannot arm shows at the onset instead of at the first `prove`: `ProbeServer.start()` (`src/server/ProbeServer.ts:105-126`) serves standard input and constructs no `Probe`; the first admitted `prove` constructs it (`#resolveProbe`, `src/server/ProbeServer.ts:234-245`), and only then does the constructor arm the stages (`src/server/Probe.ts:159`), so the Oxlint language server, the Vitest service, and the compiler warm-up start inside that call. A failed arm is reported to that call and retried once by each later call (`#ready`, `src/server/Probe.ts:229-242`), and an Oxlint server that exits between calls is recorded (`#retire`, `src/server/stages/LintStage.ts:156`, `:173-175`) and reported only when a later inspection reaches it (`:246`). Construct and arm the `Probe` at server start, report an arming failure through the server before any call depends on it, and replace a worker that exits as soon as it exits, so no `prove` pays a startup or meets a dead worker. The user ruled this on 2026-10-03 for every tool server, beside the same change to `@orkestrel/browser`'s `browse` server. Build it on `@orkestrel/pool` 0.0.14 as `@orkestrel/browser` 0.0.23's `browse` server does: one pool per stage with `min: 1` and a `restarts` bound, `start()` at server start, `create` constructing the stage (`src/server/Probe.ts:137-139`), `destroy` calling the stage's own (`:545`) under the stage deadline, because a `destroy` hook that never settles blocks every replacement, `watch` settling on the Oxlint client's `exit` (`src/server/stages/LintStage.ts:156`), `validate` where a stage can answer a liveness check, `acquire()` for each `prove`, and the leased token's `destroy()` in place of the deadline recycle (`#recycle`, `src/server/Probe.ts:536-575`); re-pin `@orkestrel/contract` to `^0.0.19`, because pool pins it, and declare pool on the user's request of 2026-10-03.
